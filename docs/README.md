# docs/

> Methodology notes, inspirations, the longer-form thinking that sits behind the code.

Code in this repo is the *what*. This directory is the *why* and the *how I came to think this way*.

## Structure

| Path | What it holds |
|---|---|
| [`inspirations/`](./inspirations) | Talks, articles, films, games — the sources behind plotloop's worldview |
| `methodology/` *(coming)* | Long-form posts on loop design, OPC, mobile-first AI |
| `decisions/` *(coming)* | ADR-style notes on why this repo is shaped the way it is |

## Inspiration ≠ citation

The `inspirations/` directory isn't a bibliography. It's a **lineage** — what shaped the thinking, in the order I encountered it. Some entries are technical talks. Some are TV shows. Some are video games. All earned their place.
