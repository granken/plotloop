# plotloop Brand

This folder contains the project identity assets.

## Primary Mark

Use [`logo.svg`](./logo.svg) as the canonical project logo.

The logo is a black lowercase wordmark. The only custom gesture is the small gap on the third `o`, which carries the idea of a loop that can be inspected, interrupted, and pivoted.

## Rules

1. Use the black wordmark as the primary identity.
2. Keep the third-`o` gap as the only design move.
3. Do not add colored dots, blocks, connector lines, rings, paws, or mascots to the primary logo.
4. Keep generous whitespace around the wordmark.
5. Use mascot or illustration ideas only as secondary assets, not as the main logo.
